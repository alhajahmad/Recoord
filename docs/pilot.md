# First pilot

Invite a small group only after connecting and verifying a live model. Suggested audience: people planning and writing for a small business or independent project.

Ask each participant to create one real project, set its goal, use one of the three starting journeys, save a useful answer as a document, edit it, and return later to continue. Check that they can identify what is saved and what is sent to the provider. Avoid collecting sensitive project content in feedback.

Record task completion, points of confusion, whether the saved document is useful, and whether the participant returns within a week. Interview participants directly rather than adding analytics without a deliberate privacy decision. Use results to decide what to improve before adding integrations, autonomous actions, or many model choices.

This is a pilot protocol, not evidence that users have completed a pilot. No invitations have been sent.
