# Security

Do not post credentials, private conversations, or exploitable user data in public issues. Repository operators should enable private vulnerability reporting and publish a monitored contact before accepting public reports. No reporting mailbox is provisioned in this source release.

Sites deployment requires the Sites identity dispatcher. Independent hosting requires the signed Cloudflare Access wrapper described in docs/self-host.md. Never trust browser-supplied identity headers directly. Model API keys belong only in server-side secrets. Operators own provider retention choices, spending limits, backups, and abuse response.
